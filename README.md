# Enterprise AI Reference Architecture

A production-grade reference architecture for building secure, scalable and observable Enterprise AI applications with LLMs, RAG, AI Agents and enterprise data.

## Current implementation status

The repository currently includes the AI gateway, provider abstraction, RAG pipeline, persistent PostgreSQL/pgvector storage, and a bounded agent runtime with explicit tool authorization and argument validation.

The latest CI verification is authoritative; implemented features are not considered runtime-verified until the corresponding GitHub Actions run passes.
